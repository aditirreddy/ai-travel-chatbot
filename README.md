# AI Travel Chatbot

An AI-powered travel chatbot created as a team capstone project during the Kode With Klossy AI/ML program in Summer 2026.

The chatbot helps users explore travel destinations across several Caribbean islands by answering questions about places to visit, activities, food, and other travel information.

## About the Project

Our team developed a travel chatbot that uses Retrieval-Augmented Generation (RAG) to provide responses based on travel information collected from multiple sources.

The project combines semantic search with a generative AI model so that the chatbot can retrieve relevant travel information before generating a response.

## Technologies Used

- Python
- Gradio
- Hugging Face
- Sentence Transformers
- Retrieval-Augmented Generation (RAG)
- Semantic Search
- Text Embeddings
- Large Language Models (LLMs)

## How It Works

1. Travel information is stored in text files for each destination.
2. The text is processed and divided into smaller chunks.
3. Sentence Transformers create embeddings for the travel information.
4. Semantic search identifies information relevant to the user's question.
5. Relevant information is provided to the language model as context.
6. The chatbot generates a travel response for the user.

## Destinations
